# Hackathon - Weather-Based Daily Planner

This project is a **Weather-Adaptive To-Do List** that lets you plan your tasks for the day and suggests the **best outfit** based on the current weather in your city.

---

## Features

- Check current weather in any city using the **OpenWeatherMap API**.
- Add tasks with **indoor alternatives**.
- Each task shows a **suggested outfit** based on the weather.
- Tasks are **saved in your browser** using localStorage, so they persist after refresh.
- Remove tasks when they are done.

---

## How to Use

1. Type your city in the input field and click **Check Weather**.
2. Add tasks with optional indoor alternatives.
3. The app will automatically suggest an outfit for each task.
4. Tasks will stay saved even if you refresh the page.
5. Click **Remove** to delete tasks.
